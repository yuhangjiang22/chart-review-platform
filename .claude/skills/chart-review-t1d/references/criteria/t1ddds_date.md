# Criterion: t1ddds_date

## Definition

The **assessment/completion date** of the T1D-DDS.

## Extraction guidance

- Report an ISO date **`YYYY-MM-DD`** (explicit assessment date preferred).
- Leave **blank/unanswered** if no T1D-DDS or no date is documented.
- Cite the row/span carrying the date.
