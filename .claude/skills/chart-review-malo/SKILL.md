# MALO (N1T-MC-MALO) trial pre-screening — notes lane

Answer one trait at a time from the chart. Do not decide eligibility; the logic
that combines traits lives outside this skill.

## Answers

`condition_met` / `condition_not_met` / `unknown` / `not_applicable`.

- **Absence of evidence is `unknown`, never `condition_not_met`.** Answer
  `condition_not_met` only on an affirmative negative statement in the record.
- Quote the chart text you relied on, verbatim, with the note it came from.
- Put the reasoning in `rationale`, including anything that makes the answer
  uncertain.

## What this skill does NOT contain

Each criteria file carries the trait as written by the decomposition component,
its parent protocol criterion verbatim, and any protocol definitions attached to
it. **It carries no per-trait decision rules** — no thresholds for undefined
terms, no guidance on conflicting or stale evidence, no worked examples. Those
have not been written for MALO. Where a trait turns on a word the protocol does
not define, say so in `rationale` and answer `unknown` rather than inventing a
threshold.

Several traits ask about things a pre-screening chart cannot carry — consent
acts, trial-visit measurements, future intentions. Answer `unknown` and record
why; do not infer.
